Motion

Hover/focus transitions: 150ms ease-out. Modal/toast enter: 200ms ease-out, exit 120ms ease-in. No motion on data updates — tables/cards swap instantly, nothing here should feel "animated app," it should feel like a report.

Focus ring: 3px accent glow at 25% opacity, no border-radius change. Error reuses the same ring pattern in red — the only place red is allowed, and only for invalid input, never for "loss" data (losses stay neutral in tables).

Principles

  • One dark background, one card surface, one accent — no secondary hues.
  • Emphasis = accent-tinted background (8–14% opacity) + border, never a new color.
  • 12px card radius, 8px control radius, 20px pill radius — three radii total.
  • Every clickable stat row/cell gets a hover tint signaling "this generates a card."
  • Mobile: stack the form, drop side padding to 12–20px, shrink the stat card to 280px.
  • Fan-facing extras (trophy case, awards, bracket) use only original iconography and copy — no NFL/team logos, wordmarks, or player likenesses.
  • Red is reserved exclusively for invalid-input error states — never used for losses/negative stats, which stay neutral.
